# 트랙세트 설치 가이드

**대상 상품**: 스피드 루프 트랙세트 - PRD-025
**권장 연령**: 5세 이상
**예상 소요 시간**: 약 20분

## 설치 순서

### 1단계: 공간 확보
넓고 평평한 바닥에 트랙 조각들을 모두 펼쳐놓으세요.

### 2단계: 출발대 조립
출발대(높은 탑)를 먼저 조립합니다. 기둥 4개를 바닥판에 끼우세요.

### 3단계: 내리막 트랙
내리막 트랙을 출발대 위에서 아래로 연결합니다.

### 4단계: 루프 설치
루프(360도 원형) 트랙을 바닥 구간에 연결합니다.

### 5단계: 후속 트랙
루프 후 직선 트랙 → 커브 트랙 → 도착 구간 순서로 연결하세요.

### 6단계: 안정성 확인
모든 연결부가 단단히 결합되었는지 확인합니다.

### 7단계: 테스트 주행
미니카를 출발대 위에 올려놓고 가볍게 밀어주면 출발!

## 팁
- 루프를 통과하지 못하면 출발대 높이를 더 올려보세요
- 트랙 연결부가 느슨하면 미니카가 이탈할 수 있습니다
