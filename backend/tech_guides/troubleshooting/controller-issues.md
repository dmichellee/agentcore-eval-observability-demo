# 앱 연결이 안 될 때 해결 방법

**대상 상품**: 앱 연동 스마트 RC카 (PRD-010)

## 증상
- 블루투스 연결이 안 됨
- 앱에서 기기가 검색되지 않음
- 연결이 자주 끊어짐

## 해결 순서

### 1단계: 블루투스 확인
스마트폰의 블루투스가 켜져 있는지 확인하세요.

### 2단계: RC카 상태 확인
RC카의 전원을 켜고 블루투스 LED가 깜빡이는지 확인하세요 (페어링 대기 상태).

### 3단계: 앱 업데이트
Vroom&Dash 앱을 최신 버전으로 업데이트하세요.

### 4단계: 기기 검색
앱에서 '기기 검색'을 눌러 RC카를 찾으세요.

### 5단계: 거리 확인
스마트폰과 RC카의 거리를 1m 이내로 가까이 하세요.

### 6단계: 간섭 제거
다른 블루투스 기기가 너무 많으면 연결이 어려울 수 있습니다. 불필요한 기기를 끄세요.

### 7단계: 전원 재시작
RC카의 전원을 끄고 10초 후 다시 켜서 재시도해보세요.

### 8단계: 앱 재설치
앱을 삭제 후 재설치해보세요.
