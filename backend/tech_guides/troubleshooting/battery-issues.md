# 배터리 문제 해결 가이드

**대상 상품**: 전체 RC카 제품

## 증상별 해결 방법

### 충전이 안 될 때
1. 충전 케이블이 제대로 연결되었는지 확인하세요
2. 충전기가 정상인지 다른 기기로 테스트해보세요
3. 배터리 커넥터에 먼지나 이물질이 없는지 확인하세요
4. 배터리가 너무 방전된 경우 연결 후 10분 정도 기다려보세요

### 배터리가 금방 닳을 때
1. 새 배터리로 교체 시기가 아닌지 확인하세요 (300회 이상 충전 시 성능 저하)
2. 완충 후 사용하세요 (반충전 상태에서 사용하면 성능이 저하됩니다)
3. 모터에 과부하가 걸리지 않는지 확인하세요 (카펫 위 사용 시 부하 증가)
4. 기온이 낮으면(10도C 이하) 배터리 성능이 저하됩니다

### 배터리가 부풀어 올랐을 때
1. 즉시 사용을 중단하세요
2. 배터리를 RC카에서 분리하세요
3. 통풍이 잘 되는 곳에 두세요
4. 고객센터(1588-VROOM)에 연락하여 교체를 요청하세요
5. 절대로 구멍을 뚫거나 분해하지 마세요
