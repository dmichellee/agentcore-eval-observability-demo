# 충전식 배터리 충전 방법

**대상 상품**: 스피드 레이서 RC카 (PRD-001) 및 충전식 배터리 RC카 전체

## 충전 순서

1. RC카의 전원을 끈 상태에서 충전하세요.
2. 배터리 팩을 RC카에서 분리합니다 (차체 아래쪽 배터리 커버 열기).
3. 포함된 USB 충전 케이블을 배터리 팩 충전 포트에 연결합니다.
4. USB 반대쪽을 충전기(5V/1A) 또는 컴퓨터 USB 포트에 연결합니다.
5. 충전 LED가 빨간색으로 점등되면 충전 중입니다.
6. LED가 녹색으로 바뀌면 충전 완료! (약 2~3시간 소요)
7. 충전 완료 후 반드시 케이블을 분리해주세요 (과충전 방지).
8. 충전된 배터리를 RC카에 다시 장착합니다.

## 주의사항
- 충전 중에는 RC카를 사용하지 마세요
- 포함된 충전기만 사용하세요
- 배터리가 뜨거워지면 충전을 즉시 중단하세요
