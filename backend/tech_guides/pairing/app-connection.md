# 변신 로봇 RC카 리모컨 사용법

**대상 상품**: 변신 로봇 RC카 (PRD-008)

## 자동 페어링
RC카와 리모컨의 전원을 켜면 약 2초 이내에 자동으로 페어링됩니다.

## 조종 방법

### 자동차 모드
- **왼쪽 스틱**: 전진 / 후진
- **오른쪽 스틱**: 좌회전 / 우회전
- **변신 버튼** (중앙 큰 버튼): 자동차 → 로봇으로 변신!

### 로봇 모드
- **왼쪽 스틱**: 앞으로 걷기 / 뒤로 걷기
- **오른쪽 스틱**: 왼쪽 회전 / 오른쪽 회전
- **변신 버튼**: 로봇 → 자동차로 변신!

### 특수 기능 버튼
- **사운드 버튼**: 자동차 모드에서는 엔진 소리, 로봇 모드에서는 변신 효과음
- **LED 버튼**: 헤드라이트(자동차) / 눈(로봇) LED ON/OFF

## 주의사항
- 변신 중에는 조종 스틱을 움직이지 마세요
- 평평한 바닥에서 변신하세요
- 변신 동작이 멈추면 방해하는 물체가 있는지 확인하세요
