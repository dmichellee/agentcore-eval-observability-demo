# 2.4GHz 리모컨 페어링 방법

**대상 상품**: 스피드 레이서 RC카 (PRD-001) 및 2.4GHz 리모컨 RC카 전체

## 페어링 순서

1. RC카와 리모컨의 전원을 모두 끕니다.
2. RC카의 전원을 먼저 켭니다. 수신기 LED가 빠르게 깜빡입니다.
3. 3초 이내에 리모컨의 전원을 켭니다.
4. 리모컨의 트리거를 한 번 당겼다 놓으세요.
5. RC카의 수신기 LED 변화: 빠르게 깜빡임 → 느리게 깜빡임 → 점등(고정) = 페어링 성공!
6. 리모컨 스틱을 움직여 RC카가 반응하는지 확인하세요.

## 페어링이 안 될 때
- 주변에 다른 2.4GHz 기기가 많지 않은 곳에서 다시 시도하세요
- 리모컨과 RC카의 거리를 1m 이내로 가까이 하세요
- 양쪽 배터리/건전지가 충분한지 확인하세요
- RC카 전원 → 리모컨 전원 순서를 지켜주세요 (3초 이내)
