# 블루투스 페어링 방법

**대상 상품**: 앱 연동 스마트 RC카 (PRD-010)

## 사전 준비
- 스마트폰에 'Vroom&Dash Smart' 앱 설치 (App Store / Google Play)
- RC카 배터리 충전 확인

## 페어링 순서

1. RC카의 전원을 켜세요. 블루투스 LED가 파란색으로 깜빡입니다.
2. 스마트폰의 블루투스를 켜세요.
3. 앱을 실행하고 '기기 연결' 버튼을 누르세요.
4. 검색된 기기 목록에서 'VD-SMART-XXXX'를 선택하세요.
5. 연결이 완료되면 앱 화면에 조종 인터페이스가 나타납니다.

## 조종 모드 선택
앱에서 3가지 조종 방식 중 선택 가능:
- **조이스틱 모드**: 화면의 가상 조이스틱으로 조종
- **기울기 센서 모드**: 스마트폰을 기울여서 조종
- **버튼 모드**: 방향 버튼으로 조종

## FPV 카메라 사용
앱 메인 화면에서 '카메라' 아이콘을 누르면 RC카에 장착된 카메라의 실시간 영상을 볼 수 있습니다.
